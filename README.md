# Press Metal MIS

Management Information System for Press Metal Industries, Plant E-47: P&L, how profit is made, 3-year comparison, profit levers, cost explorer, debt and balance sheet.

- `index.html` — the app (opens on GitHub Pages)
- `firebase-config.js` — Firebase project settings (not secret)

Figures, logins and backups are stored in Firebase and can only be read after signing in. Access is enforced by Firestore security rules. Never upload data backup files (.json) to this repository.

Monthly update: sign in as Admin or Editor → Data → Upload MIS workbook (sheet PMI-E47).
